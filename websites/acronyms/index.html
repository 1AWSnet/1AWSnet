#ABCDEFHILMNOPQRSTUVWZ

Acronyms

IT, networking, security, cameras and phones.

#

2FA
Two-Factor AuthenticationLogging in with two proofs, e.g. a password plus a code. A type of MFA.

A

A record
Address recordDNS record that points a domain name to an IPv4 address.
ACL
Access Control ListRules on a router, firewall or file that say who or what is allowed through.
AI
Artificial IntelligenceSoftware that does tasks that normally need human judgment, like chatbots or voice cloning.
ALPR
Automatic License Plate RecognitionCameras and software that read vehicle plates. Also called LPR or ANPR.
API
Application Programming InterfaceA defined way for one program to talk to another.
AWS
Amazon Web ServicesAmazon's cloud platform for servers, storage and hosting.

B

BEC
Business Email CompromiseScam emails pretending to be the boss or a vendor to get wire transfers or bank changes.
BGP
Border Gateway ProtocolHow ISPs and large networks tell each other which IP addresses they can reach.
BIOS
Basic Input/Output SystemOlder firmware that starts a computer before the operating system. Replaced by UEFI.

C

CCTV
Closed-Circuit TelevisionSecurity camera systems that record to a private system, not broadcast.
CDN
Content Delivery NetworkServers around the world that cache a website so it loads fast everywhere (e.g. Cloudflare).
CNAME
Canonical Name recordDNS record that makes one name an alias of another name.
COOP
Continuity of Operations PlanHow an organization keeps its essential work running during and after a disaster or major outage.
COOP
Cross-Origin-Opener-PolicyWeb security header that isolates a page from pop-ups and tabs opened from other sites.
CVE
Common Vulnerabilities and ExposuresPublic ID numbers for known security flaws, e.g. CVE-2024-12345.

D

DDoS
Distributed Denial of ServiceFlooding a site or network with traffic from many machines to knock it offline.
DHCP
Dynamic Host Configuration ProtocolHands out IP addresses to devices automatically when they join a network.
DID
Direct Inward DialingA phone number that rings straight to a specific extension on a PBX.
DKIM
DomainKeys Identified MailSigns outgoing email so receivers can check it really came from your domain.
DMARC
Domain-based Message Authentication, Reporting and ConformanceTells receivers what to do with email that fails SPF/DKIM, and sends reports.
DNS
Domain Name SystemTurns names like 1aws.net into IP addresses. The internet's phone book.
DVR
Digital Video RecorderRecords analog/coax cameras. NVR is the IP-camera equivalent.

E

EDR
Endpoint Detection and ResponseSecurity software on each computer that watches for and stops attacks.

F

FIM
File Integrity MonitoringWatches important files for changes and alerts on anything unexpected (e.g. Wazuh, Tripwire).
FOV
Field of ViewHow wide an area a camera lens can see, in degrees.

H

HDD
Hard Disk DriveSpinning-disk storage. Cheaper per TB, slower than SSD.
HIPAA
Health Insurance Portability and Accountability ActUS law that sets privacy and security rules for PHI at healthcare providers, insurers and their vendors.
HTTPS
Hypertext Transfer Protocol SecureEncrypted web traffic (the padlock). Encrypted does not mean the site is safe.

I

ICMP
Internet Control Message ProtocolNetwork error and test messages. What ping uses.
IDF
Intermediate Distribution FrameA secondary network closet that connects back to the MDF.
IDS
Intrusion Detection SystemWatches network traffic and alerts on attacks.
IP
Internet ProtocolThe addressing system for devices on a network, e.g. 192.168.1.10.
IPMI
Intelligent Platform Management InterfaceOut-of-band server management: power and console even if the OS is down (iDRAC, iLO).
IPS
Intrusion Prevention SystemLike IDS, but also blocks the attack.
IR
InfraredLight cameras use for night vision; IR LEDs light the scene invisibly.
ISP
Internet Service ProviderThe company that sells the internet connection.
IT
Information TechnologyComputers, networks, phones and the people who run them.
IVR
Interactive Voice ResponseThe phone menu: "Press 1 for sales...".

L

LAN
Local Area NetworkThe network inside one building or site.
LXC
Linux ContainersLightweight containers; Proxmox uses them alongside VMs.

M

MAC
Media Access Control addressThe hardware address burned into each network interface.
MDF
Main Distribution FrameThe main network/telecom room where the ISP line comes in.
MFA
Multi-Factor AuthenticationLogging in with more than one proof: password, app code, hardware key.
MX
Mail Exchanger recordDNS record that says which server receives email for a domain.

N

NAS
Network Attached StorageA storage box shared over the network (e.g. TrueNAS).
NAT
Network Address TranslationLets many private devices share one public IP address.
NUT
Network UPS ToolsSoftware that monitors a UPS and shuts servers down safely on power loss.
NVR
Network Video RecorderRecords IP cameras (e.g. Frigate, Blue Iris).

O

ONVIF
Open Network Video Interface ForumStandard that lets cameras and NVRs from different brands work together.
OpSec
Operations SecurityProtecting information that attackers could piece together and use.
OSINT
Open-Source IntelligenceInformation gathered from public sources like social media and websites.
OSPF
Open Shortest Path FirstA routing protocol used inside an organization's network.

P

PBX
Private Branch ExchangeA business phone system that handles extensions and outside lines (e.g. FreePBX).
PGP
Pretty Good PrivacyEncrypts and signs email and files with public/private key pairs. GPG (GnuPG) is the free version.
PHI
Protected Health InformationAny health or medical info tied to a person. HIPAA controls how it's stored, shared and secured.
PKI
Public Key InfrastructureThe system of certificates and authorities behind HTTPS and signing.
PoE
Power over EthernetPower and data on the same network cable. Runs cameras, phones and access points.
PTZ
Pan-Tilt-ZoomA camera that can move and zoom remotely.

Q

QoS
Quality of ServicePrioritizing traffic, e.g. voice calls before downloads.
QR
Quick Response codeSquare barcode phones scan. Malicious ones are "quishing".

R

RAID
Redundant Array of Independent DisksCombining drives for speed and/or surviving a drive failure. Not a backup.
RDP
Remote Desktop ProtocolWindows remote desktop. Never expose it straight to the internet.
RTSP
Real Time Streaming ProtocolHow IP cameras send live video to an NVR or app.

S

SaaS
Software as a ServiceSoftware you rent and use online, e.g. Microsoft 365.
SAN
Storage Area NetworkDedicated network giving servers block-level storage.
SASE
Secure Access Service EdgeNetworking and security (firewall, VPN/ZTNA, web filtering) delivered from the cloud instead of on-site boxes.
SFP
Small Form-factor PluggableSwappable module that adds a fiber or copper port to a switch.
SIEM
Security Information and Event ManagementCollects logs from everything and alerts on suspicious patterns.
SIM
Subscriber Identity ModuleThe card that ties a phone to a number. "SIM swap" steals the number.
SIP
Session Initiation ProtocolThe protocol VoIP phones use to set up calls.
SMS
Short Message ServiceText messages. Weak for MFA because of SIM swaps.
SPF
Sender Policy FrameworkDNS record listing which servers may send email for your domain.
SSD
Solid-State DriveFlash storage with no moving parts. Faster than HDD.
SSH
Secure ShellEncrypted command-line access to a remote machine.
SSID
Service Set IdentifierThe Wi-Fi network name.
SSL
Secure Sockets LayerThe old name for TLS. Still used casually ("SSL certificate").
SSO
Single Sign-OnOne login that gets you into many apps.
STP
Spanning Tree ProtocolStops network loops between switches. Also: Shielded Twisted Pair cable.

T

TCP
Transmission Control ProtocolReliable, ordered network delivery. Used by web and email.
TLS
Transport Layer SecurityThe encryption behind HTTPS and secure email.
TXT
Text recordDNS record holding text; used for SPF, DKIM, DMARC and domain verification.

U

UDP
User Datagram ProtocolFast, no-guarantee network delivery. Used by voice, video and DNS.
UEFI
Unified Extensible Firmware InterfaceModern replacement for BIOS. Supports Secure Boot.
UPS
Uninterruptible Power SupplyBattery backup that keeps equipment running through outages.
URL
Uniform Resource LocatorA web address, e.g. https://1aws.net/pages/faq.html.
USB
Universal Serial BusThe standard port for drives and peripherals. Never plug in found USB drives.
UTM
Unified Threat ManagementA firewall that also does antivirus, web filtering and IPS in one box.

V

VE
Virtual EnvironmentAs in Proxmox VE, the hypervisor.
VLAN
Virtual LANSplits one physical network into separate isolated networks.
VM
Virtual MachineA full computer running in software on a hypervisor.
VoIP
Voice over Internet ProtocolPhone calls over the network instead of copper phone lines.
VPN
Virtual Private NetworkEncrypted tunnel between a device and a network (e.g. WireGuard, Tailscale).

W

WAN
Wide Area NetworkThe network outside your site; usually means the internet connection.
WDR
Wide Dynamic RangeCamera feature that handles bright and dark areas in the same shot.
Wi-Fi
Wireless networking (IEEE 802.11)Trademark name, not an abbreviation of anything.
WLAN
Wireless LANA local network over Wi-Fi.

Z

ZFS
Zettabyte File SystemFile system with built-in RAID, snapshots and corruption checks. Used by TrueNAS.
ZTNA
Zero Trust Network AccessEvery user and device is checked every time; nothing is trusted just for being inside.
