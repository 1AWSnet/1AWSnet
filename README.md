# website
Source code and files for 1AWS.net website.

## Structure
Each business site lives in its own folder under `/websites`.

## Architecture
- **Repository:** [github.com/1AWSnet/1AWSnet](https://github.com/1AWSnet/1AWSnet) (branch: `main`)
- **Hosting/CDN:** Cloudflare, connected to the GitHub repo — pushes to `main` deploy live within seconds.
